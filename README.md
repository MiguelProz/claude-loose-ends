# claude-loose-ends

Marketplace de un mod de Claude Code: **loose-ends**, el cuaderno de la sesión
con Chispa. Requiere Claude Code 2.1.287 o posterior (probado con 2.1.288).

    /plugin marketplace add MiguelProz/claude-loose-ends
    /plugin install loose-ends@claude-loose-ends
    /reload-plugins

Detalle en [loose-ends/README.md](loose-ends/README.md).
